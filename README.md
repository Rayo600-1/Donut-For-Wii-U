# Donut-For-Wii-U

An ASCII rotating donut animation for the **Nintendo Wii U**.

## About

Donut-For-Wii-U is a homebrew project that brings the classic rotating ASCII donut animation to the Nintendo Wii U.

The animation is rendered independently on the TV and GamePad screens.

## Features

- Classic rotating ASCII donut animation.
- Independent rendering for TV and GamePad.
- Centered and scaled GamePad display.
- 15 FPS target.
- On-screen FPS counter.
- No external audio dependencies.

## Requirements

- Nintendo Wii U.
- Homebrew environment.
- [devkitPro](https://devkitpro.org/)
- [WUT (Wii U Toolchain)](https://github.com/devkitPro/wut)

## Building

Clone the repository:

```bash
git clone https://github.com/Rayo600-1/Donut-For-Wii-U.git
cd Donut-For-Wii-U
```

Build the project:

```bash
make
```

## Controls

- **HOME:** Exit the application.
- **MINUS / PLUS:** Exit the application.
